# Flavor — Restaurant Template

A free, open-source restaurant website template built with React 19, Tailwind CSS 4, and TypeScript.

## Features

- Fixed transparent navbar with mobile hamburger menu
- Full-screen hero with background image and dark overlay
- Info bar with contact details and lucide icons
- About section with two-column layout
- Specialties section with dish cards
- Parallax intro section with CTA
- Tabbed menu with Main, Desserts, and Drinks categories
- Testimonials section with parallax background
- Reservation form with client-side validation
- Footer with About, Blog, Instagram, Newsletter columns
- Social icons (Facebook, Twitter, Instagram, Dribbble)

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
