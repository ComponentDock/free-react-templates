# Spec: BtnDash (Bootstrap Buttons 20)

## Overview

BtnDash is a modern React implementation of ColorLib Bootstrap Buttons V20 (`https://colorlib.com/wp/template/bootstrap-buttons-20/`), featuring animated buttons, hover states, interactive click ripples, and action showcases.

## Requirements

- Requirement 1: Navbar with brand title and navigation links.
- Requirement 2: Hero section introducing animated button collections.
- Requirement 3: Showcase sections for various animated buttons and interactive button states.
- Requirement 4: Playground section to test button variants and click actions.
- Requirement 5: Footer linking to Component Dock (`https://www.componentdock.com/`).
